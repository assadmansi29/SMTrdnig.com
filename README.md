# SMTrading.com - Institutional Trading Platform & Publication

Official portal for **Smart Money Trading (SMC)** by **Abu Asad Almansi**. Features institutional market breakdowns, macroeconomic insights, live TradingView charts, quantitative calculator tools, and an integrated E-Commerce store for PineScript indicator suites, algorithmic bots, and masterclasses.

## 🚀 Features

- **Live Trading Terminal**: Embedded TradingView interactive charting with quick multi-asset selection (Gold XAUUSD, Nasdaq NAS100, Dow Jones US30, DAX GER40) and multiple timeframe presets.
- **Institutional Publication & Articles**: Curated Smart Money Concept breakdowns, liquidity sweep mechanics, and macroeconomic analyses with category filters, bookmarking, and instant search (`Cmd/Ctrl + K`).
- **Interactive E-Commerce Store**: Institutional PineScript suites, Abu Asad Almansi video masterclasses, algorithmic execution bots, and hardware trading accessories with interactive cart and promo code discounts.
- **Trader Toolkit**:
  - Position Size & Lot Sizing Calculator (dynamic Risk %, pip value, stop-loss calculations)
  - Institutional Economic Calendar with high-impact event tracking
  - Live Crypto & Market Fear / Greed Sentiment Gauge
- **VIP Alpha Dispatch**: Real-time newsletter subscription modal for high-probability setups and institutional morning notes.

## 🛠 Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion
- **Icons**: Lucide React
- **Build Tool**: Vite 6

## 📦 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/smtrading.git
cd smtrading

# Install dependencies
npm install

# Start local development server (runs on port 3000)
npm run dev
```

### Production Build

```bash
# Build the production bundle
npm run build

# Preview the production build
npm run preview
```
